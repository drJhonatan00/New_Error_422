## Overview

**New Error 422** is a custom modification inspired by the classic glitch/creepypasta survival mythos. Unlike surface-level cosmetic mods, this project manipulates low-level game triggers, UI rendering pipelines, entity behaviors, and audio buses to create a genuinely chaotic, glitch-infested environment.

> *"The game code is breaking down. Rules no longer apply."*

---

## Key Features

* **Anomalous UI & HUD Distortion**: Dynamic inventory glitches, shifting text overlays, and corrupted status indicators.
* **Unpredictable Entity AI**: Bosses and mobs exhibit erratic behavior, altered hitboxes, and real-time texture corruption.
* **Custom Audio Engine & Sound Scapes**: Custom-composed dark atmospheric audio tracks and sudden frequency-bent sound effects.
* **Corrupted World Logic**: Random gravity shifts, inverted physics, and anomalous block transformations triggered under specific survival conditions.
* **Multi-Language Interface**: Complete localization support built into the modification assets.

## Quick Start / Installation

1. Download the latest release `.jar` file from the [Releases Page](../../releases).

4. Launch the game and prepare for unpredictable anomalies.
